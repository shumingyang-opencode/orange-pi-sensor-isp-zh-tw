多相機

支援多 CSI 的板卡（如 RK3588 多通道）可同時接多顆感測器；用 media-ctl 建立多條管線，每顆一個 video device。

客製 OV 感測器接入流程

  1. 確認驅動支援：OV5640/OV5647 等有 mainline 驅動。
  2. 改 device tree：宣告 I2C 位址、reset/clock、MIPI 通道。
  3. 改驅動 init table：依公開 register 資料調整。
  4. 驗證出圖 → 再做校正。
NDA 提醒：完整 register 表常需 NDA；本站只用公開資料。正式開發以 OVT 官方文件為準。

完整案例：在 Orange Pi 調校 OV5640

改 DT→probe 成功→取流→曝光/白平衡→後處理
  1. dmesg 確認 ov5640 probe 成功、讀到 ID。
  2. v4l2-ctl 取一幀，確認格式。
  3. 手動曝光/增益確認影像曝光正確。
  4. 關 AWB 手動調 gains 確認色彩中性。
  5. 後處理補 LSC/NR/Sharpen。
  6. 不同場景回歸。

最佳實踐

  • 先確認板卡 BSP「已知可用組合」。
  • 固定測試場景，量化比較。
  • 一次只改一個參數。
  • 記錄每次改動與前後圖。
