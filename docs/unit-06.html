Bring-up 四件事

檢查項驗證方式
電源AVDD/DVDD/DOVDD 到位
ClockXCLK/MCLK 有輸出（示波器 / dmesg）
I2Ci2cdetect + 讀 ID
MIPIdmesg 無 CSI 錯誤、media 有資料

用 dmesg 追線索

常見除錯指令
dmesg | grep -i -E "ov5640|csi|mipi|v4l2"
cat /sys/kernel/debug/gpio | grep -i reset

Register dump 與回讀

透過驅動讀 register
v4l2-ctl -d /dev/v4l-subdev0 -C exposure            # 讀曝光 control
i2cget -y 3 0x3c 0x3500                              # 直接讀 register

常見 Bring-up 症狀

症狀方向
v4l2 開 stream 失敗media 管線沒設好 / 驅動 probe 失敗
全黑曝光為 0、感測器沒輸出、格式錯
綠/紫畫面Bayer/顏色格式錯（V4L2 格式設定）
dmesg probe error上電/clock/reset 腳位或 I2C 位址錯
Orange Pi 特別注意：不同板卡 BSP 的管線節點、位址、格式支援都不同——先確認你板卡的「已知可用組合」。

  • 透過 controls 與 i2c 讀 register。
  • 四種常見症狀的排查方向。
