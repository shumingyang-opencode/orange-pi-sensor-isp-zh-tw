Bring-up 四件事

檢查項驗證
電源AVDD/DVDD/DOVDD 到位
ClockXCLK/MCLK 有輸出（示波器 / dmesg）
I2Ci2cdetect + 讀 ID
MIPIdmesg 無 CSI 錯誤、media 有資料

用 dmesg 追線索

常見除錯指令
dmesg | grep -i -E "ov5640|csi|mipi|v4l2|probe"
cat /sys/kernel/debug/gpio | grep -i reset

Register dump 實作

透過 controls 與 i2c 讀
v4l2-ctl -d /dev/v4l-subdev0 -C exposure     # 讀曝光 control
v4l2-ctl -d /dev/v4l-subdev0 -C analogue_gain
for r in 0x3500 0x3501 0x3502 0x3503; do
  echo -n "$r: "; sudo i2ctransfer -y 3 w2@0x3c ${r:2:2} ${r:4:2} r1
done

Bring-up 決策樹

「沒畫面」決策樹
1. dmesg 有 ov5640 probe？
   ├─ error → 電源/clock/reset/位址
   └─ ok ─┐
2. i2cdetect 看到 0x3c？讀到 0x5640？
   ├─ 否 → I2C/位址問題
   └─ 是 ─┐
3. v4l2-ctl 取到幀？
   ├─ 否 → media 管線/格式
   └─ 是 → 基本 bring-up ✅
Orange Pi 特別注意：各板卡 BSP 的節點/位址/格式都不同——先確認你板卡「已知可用組合」。
看完這單元你應該能說出：
  • Bring-up 四件事。
  • 用 dmesg 追 probe/CSI 錯誤。
  • 透過 controls 與 i2c 讀 register。
  • 照決策樹排解。
