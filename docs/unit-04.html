V4L2 subdev 模型

/dev/v4l-subdev0（感測器）→/dev/v4l-subdev1（CSI）→/dev/video0

ov5640.c 驅動（mainline 範本）

  • 實作 V4L2 subdev 介面：s_power、s_stream、s_ctrl…
  • 提供曝光/增益/白平衡 controls（V4L2_CID_EXPOSURE 等）。
  • 內含感測器 init register table。

查看 media 管線（實作）

media-ctl / v4l2-ctl
media-ctl -p -d /dev/media0     # 列出所有實體與連結
v4l2-ctl --list-devices         # 對應的 /dev/videoX
v4l2-ctl -d /dev/v4l-subdev0 --list-ctrls   # 列出感測器 controls
調適關鍵：V4L2 controls（曝光、gain、白平衡）就是「感測器 register 的抽象介面」——調校透過它們，不手寫 register。
看完這單元你應該能說出：
  • V4L2 subdev 與 media 管線。
  • ov5640.c 是 Linux 驅動範本。
  • V4L2 controls 是 register 的抽象。
  • media-ctl/v4l2-ctl 查管線與 controls。
