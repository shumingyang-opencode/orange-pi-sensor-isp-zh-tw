V4L2 subdev 模型

感測器在 Linux 裡是「subdev」：透過 media controller 與 CSI 接收器、video device 串成管線。

/dev/v4l-subdev0（感測器）→/dev/v4l-subdev1（CSI）→/dev/video0

ov5640.c 驅動

ov5640.c 已進 Linux mainline，是學習感測器驅動的最佳範本：

  • 實作 V4L2 subdev 介面（s_power、s_stream、s_ctrl…）。
  • 提供曝光/增益/白平衡 controls（V4L2_CID_EXPOSURE 等）。
  • 內含感測器 init register table。
查看 media 管線
media-ctl -p -d /dev/media0
v4l2-ctl --list-devices
調適關鍵：V4L2 controls（曝光、gain、白平衡）就是「感測器 register 的抽象介面」——調校時透過它們，而不是手寫 register。
看完這單元你應該能說出：
  • V4L2 subdev 與 media 管線結構。
  • ov5640.c 是 Linux 感測器驅動範本。
  • V4L2 controls 是 register 的抽象。
  • media-ctl / v4l2-ctl 查看管線。
