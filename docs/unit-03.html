I2C 位址與讀寫

OV5640 的 7-bit I2C 位址常見 0x3C（寫）/ 0x3D（讀），也可經 0x3008[6] 切換。Linux 下用 i2c-tools 驗證：

掃描與讀 ID
i2cdetect -y 3                  # 依板卡調整匯流排編號
i2cget -y 3 0x3c 0x300a          # 讀 OV5640 ID 高位（0x56）

OV5640 register 慣例

Register功能
0x300A/0x300B感測器 ID（0x56 / 0x40）
0x3035/0x3036PLL 分頻
0x3500–0x3503曝光時間（AEC）
0x350A–0x350B類比增益（AGC）
0x4740–0x4742MIPI 介面設定
除錯第一招：接上感測器讀不到 ID，先查 I2C 位址、上電、RESET 腳位——「根本沒通訊」是 bring-up 最常見的開場。
