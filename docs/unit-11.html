AWB 原理

不同色溫的光源會讓白色偏色。AWB 對 R/G/B 套不同 gains 把白校正回白。OV5640 內建 AWB 演算法（register 群 0x5180 起）。

OV5640 AWB 開關與手動

V4L2 白平衡 control
v4l2-ctl -d /dev/v4l-subdev0 -c auto_n_white_balance=0   # 關 AWB
v4l2-ctl -d /dev/v4l-subdev0 -c red_balance=128          # R gain（依驅動比例）
v4l2-ctl -d /dev/v4l-subdev0 -c blue_balance=128         # B gain
調適陷阱：感測器端 AWB 對複雜光源（混合色溫）常不準。要精準色彩，最好關閉感測器 AWB、改由平台端做（若有 ISP）。

色彩與 CCM

OV5640 內建色彩校正，但可調空間有限。要「分色溫 CCM」需平台 ISP（如 RK3588）。

實務：先在感測器端把 AWB 調到「中性」，再用平台/後處理做色彩喜好——分層處理較可控。
