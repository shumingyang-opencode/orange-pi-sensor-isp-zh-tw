Orange Pi 定位：調校功能最弱，但「最貼近 Linux 底層」——適合想徹底理解感測器 register 與 V4L2 的工程師；追求畫質時升級到 RPi5 / NVIDIA。

選型建議

  • 學感測器底層 → Orange Pi（V4L2 原生）。
  • 開源調校 → RPi5。
  • 高品質量產 → Orin Nano。
  • 次世代機器人 → Thor T5000。
