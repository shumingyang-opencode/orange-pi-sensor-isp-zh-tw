為什麼學這套課程？

Orange Pi 不像 RPi5 有統一 libcamera 堆疊——各板卡的相機支援散在 BSP 內核。正因如此，理解 V4L2 感測器驅動 + media controller + register 就特別重要：這是 Linux 相機調適的「通式」，學了到處能用。

本課程以 OV5640（Orange Pi 最常見的 OmniVision 感測器）為主例。
