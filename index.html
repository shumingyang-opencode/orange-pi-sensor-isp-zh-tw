為什麼學這套課程？

Orange Pi 不像 RPi5 有統一的 libcamera 堆疊——各板卡（RK3588、H618 等）的相機支援散落在 BSP 內核與 V4L2 驅動裡。正因如此，理解 V4L2 感測器驅動 + media controller + register 控制就特別重要：學會這套「Linux 原生」調適流程，任何板卡都能上手。

本課程以 OV5640（Orange Pi 最常見的 OmniVision 感測器）為主要實例。
