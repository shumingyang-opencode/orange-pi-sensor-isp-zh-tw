為什麼要懂子版本：Orange Pi 家族橫跨多個 SoC 世代（Rockchip RK3588、Allwinner H6xx），相機支援與效能差異極大——選錯版本可能根本沒有可用的 CSI 驅動。

子版本比較

版本SoCRAM關鍵 I/O適合開發
Orange Pi 5 PlusRK35888–32GB雙 CSI、雙 2.5G 網、PCIe 3.0高階、多相機、AI
Orange Pi 5 / 5 ProRK3588(S)8–32GBCSI、40-pin一般開發、影像
Orange Pi 3BRK35661–8GBCSI、40-pin中階、輕量影像
Orange Pi Zero 3H6181–4GBCSI（依 BSP）低成本、Linux 伺服
Orange Pi Zero 2WH6181–4GBCSI（有限）低成本、IoT

配件說明 / 用途

40-pin 擴展板GPIO/串列擴充
散熱器/風扇RK3588 高載必備

選擇建議

  • 要完整 ISP/相機調校 → 選 RK3588 系（Orange Pi 5 系列），有平台 ISP。
  • 只需 Linux 伺服/IoT → Zero 系列（H618）即可，成本低。
  • 先確認板卡 BSP 對你的感測器有驅動，再買板。
  • H6xx 系列相機支援有限——做 sensor 調校不建議。
